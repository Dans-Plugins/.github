# Dan's Plugins Community

A community-driven collection of open-source Minecraft (Spigot/Paper) plugins
led by Daniel McCoy Stephenson, focused on gameplay, roleplay and server
administration.

- Website: https://dansplugins.com
- Knowledge base: https://zettel.dansplugins.com
- Server hosting: https://dansserverhosting.com

## Notable repositories

**Medieval Factions and its expansions**

- [Medieval-Factions](https://github.com/Dans-Plugins/Medieval-Factions) — players organize into feudal, diplomatic, lawful groups akin to nations.
- [Currencies](https://github.com/Dans-Plugins/Currencies) — lets faction owners create and mint local currencies.
- [Fiefs](https://github.com/Dans-Plugins/Fiefs) — sub-factions within a faction.

**Other plugins**

- [Medieval-Roleplay-Engine](https://github.com/Dans-Plugins/Medieval-Roleplay-Engine) — tools for roleplay between players.
- [Wild-Pets](https://github.com/Dans-Plugins/Wild-Pets) — tame any entity and keep it as a pet.
- [FoodSpoilage](https://github.com/Dans-Plugins/FoodSpoilage) — food turns into rotten flesh after a configurable time.
- [SimpleSkills](https://github.com/Dans-Plugins/SimpleSkills) — an expandable skill system.
- [AlternateAccountFinder](https://github.com/Dans-Plugins/AlternateAccountFinder) — identifies accounts that have used the same IP address.
- [Dans-Plugin-Manager](https://github.com/Dans-Plugins/Dans-Plugin-Manager) — download the community's plugins in-game or from the console.

**Libraries, tooling and site**

- [Ponder](https://github.com/Dans-Plugins/Ponder) — Kotlin modules shared by console applications and plugins.
- [release-gates](https://github.com/Dans-Plugins/release-gates) — reusable workflows that boot a build on a real Spigot server before it is released.
- [dansplugins-dot-com](https://github.com/Dans-Plugins/dansplugins-dot-com) — the community website.
- [dpc-zettelkasten](https://github.com/Dans-Plugins/dpc-zettelkasten) — a linked knowledge base where every note cites a pinned source.

The full list is under [Repositories](https://github.com/orgs/Dans-Plugins/repositories).
